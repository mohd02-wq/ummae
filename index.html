How reminders work
Websites cannot reliably ring or vibrate at an exact time when fully closed. Export the calendar file, then import it into your phone calendar or Google Calendar. Calendar alerts can use your phone's own sound and vibration. In-app notifications work only when the browser allows the app or service worker to run.

To import: open Google Calendar on a computer → Settings → Import & export → select the downloaded .ics file → Import. On a phone, open the file and follow the calendar app's import option.
